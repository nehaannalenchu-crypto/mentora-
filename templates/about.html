ABOUT THE PROJECT

Matching that’s
easy to explain.

Mentora is a student project exploring whether profile preferences and feedback can help students compare peer tutors.

01

Eligibility first

The prototype filters tutors by subject. It then ranks eligible profiles using schedule overlap, language and teaching-style preferences.

02

Model, when trained

The planned logistic regression model learns from labeled student–tutor pair ratings. Until there is suitable survey data, the site uses a clearly labeled rule-based baseline.

03

Feedback with care

Feedback is stored with a random browser identifier, not a name or student number. Ratings of 1–2 become negative labels, 4–5 positive labels, and 3 stays neutral.

What a score means

A higher score means the profile fits more of the selected features or, once trained, receives a higher model score. It does not prove that a tutoring session will succeed.
